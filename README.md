# 📊 Dashboard: Анализ опозданий поставок (Logistics Delay Analytics)

## 📋 Описание
Интерактивный дашборд для мониторинга и анализа опозданий грузов в логистической цепи. 
Позволяет выявлять проблемные этапы, маршруты и причины задержек.

##  Цель проекта
- Визуализация KPI по опозданиям
- Анализ причин задержек по этапам доставки
- Выявление проблемных направлений и логистов
- Оптимизация логистических процессов

## 📊 Ключевые метрики
- **5.99%** - общий процент опоздавших грузов
- **71 тыс.** - количество опоздавших единиц
- **4.49 дня** - среднее время опоздания

## 🛠 Технологии
- Power BI
- DAX (расширенные меры и расчеты)
- Power Query (ETL-процессы)
- SQL (подготовка данных)

## 📁 Структура данных
Схема включает 8 основных таблиц:
- Спецификация груза
- План и нормативы
- Факт движения
- Причины опозданий (логистика и завод)
- Справочники (заводы, этапы, календарь)
